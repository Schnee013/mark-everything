# ME browser application

This is the adapted Raindrop.io React UI. See the root [README](../README.md), [installation guide](../docs/INSTALL.md), and [third-party notices](../THIRD-PARTY-NOTICES.md).

Only `npm run build:me:chrome` and `npm run build:me:edge` are supported ME builds. The package version retains the upstream app version; ME's release version is defined in `src/target/extension/manifest/index.js` and the helper capabilities.
